# Misión: Obtener la Barra I
Aplicación de práctica de inglés de la Mesa de Inglés (Esc. Mil. Enfría.). Se instala en el celular como app web y funciona sin internet. Se publica vacía: los datos de cada usuario se guardan solo en su dispositivo.

Incluye práctica diaria, flash cards y ejercicios de vocabulario con repetición espaciada (ALCPT y ALC), técnicas de estudio, simulacros con tiempo, competencia entre compañeros y seguimiento de avance para la coordinación.

Versión 2.11.
